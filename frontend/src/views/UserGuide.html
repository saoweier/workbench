使用教程 · 2026.10.06

从选题，到下一篇。

先做一份满意的图文，再按需要学习视频、发布和回访。

首次生成预览与调整模板与 Skill讲解视频发布与回访失败排查

01 · 做出第一篇图文

  1. 到模型设置保存服务地址、API 和模型名称，并启用文字模型。文字、图片和语音是独立能力，不需要的能力可以暂时不配。
  2. 打开创作室，从 HotPush 热榜按板块、来源选题，或直接输入自己的题目。在补充要求中说清数量、页数和想强调的信息。
  3. 进入选择样式：比较海报外观，选择密度、表达风格和页数。视觉风格与题型独立，选手绘不会把榜单改成教程。
  4. 核对摘要和生成平台，由你点击开始制作。任务会经过调研、规划、生成、审核、出图；点击任务提示查看进度。真实模式会调用你配置的模型，可能产生费用。
可以直接这样写：
给 AI 新手做一份 TOP10 工具速查，恰好2页，每页5项。每项完整名称＋一句用途。风格活跃，来源放短脚注。
如果要求“上个月最热门”，请提供可核验的时间范围和排名数据；当前聚合顺序不能替代月度统计。

文字模型通过工作台工具联网：先规划检索词，再搜索与读取正文，资料不足时针对缺口补查。未配置独立搜索接口时使用公开搜索备用入口；遇到验证页不绕过验证。检索策略在“资料调研与核验” Skill 维护，实际检索词、入口、正文和失败原因可在技能诊断页查看。

榜单只是选题线索。具体数值、软件操作、事件起源等需要可读原文；只有标题、链接或搜索摘要时，系统可能停止并请求资料。

02 · 预览不满意，就继续调整

  1. 打开集中预览，选择自己的内容。分别看两个平台的图片和发布文案，点击图放大阅读。
  2. 核对实际核心信息：TOP10 是否十项、名称与顺序是否正确；科普是否给出具体答案；教程是否能照做；图片是否真的表达了文案中的重点。
  3. 找到内容再调整，点击“更短更精简 / 更详细 / 更活跃 / 更精致”，或写自己的要求。可以补原始资料、上传自有配图、换输出样式。
  4. 修改会生成新版本；数量和页数保留，除非你明确要求改变。新版本完成后重新预览；满意后批准当前平台版本，再下载发布包。批准不会在外部平台发布。
更短更精简，删除重复说明。保留完整十项和两页，每项一句具体用途。
只调整风格更活跃，保留数值、来源口径、对象和名次。

写作长度、条目数量和排版密度由 Skill 指导，普通超长会自动排版并保留预览，不会因固定字数拒收。审核是修改建议，发现问题仍可打开成品继续调整；它不等于程序崩溃或人工批准。调研摘录默认使用提示模式，标点或转述差异不会中断任务；只有在调研 Skill 中明确设置“引用一致性处理：严格”才会严格逐字检查。发布文案字数默认也是提示；生成 Skill 的“发布文案长度处理：严格”用于需要强制字数的业务。

审核未通过或任务失败时，先看资料与生成诊断。不要只看“已出图”：有图片也可能存在待修改问题。

03 · 改模板，就是改 Skill＋配套外观

  1. 打开样式工坊，用“同题对照”比较相同内容在不同样式中的表现。“代表样例”用来了解不同题型，不限定模板用途。
  2. 选择模板，编辑写作 Skill：写哪些信息、怎么组织、必须保留什么。再调整配套模板外观：颜色、字体、布局和图案。
  3. 预览固定示例后保存，或者复制为新模板。保存的规则用于后续新任务；已有成品和进行中的任务继续用冻结版本。要应用到旧内容，回到预览页重新调整生成。
  4. 技能管理与诊断维护调研、规划、生成、审核、修改及科技、生活、游戏等题材规则。先看具体内容的执行履历，再改对应规则。

内容规划的数量规则也在技能页维护。当前默认每页要点不限、总页数不限；在“内容规划”中编辑“每页规划要点上限：不限”和“规划总页数上限：不限”，也可填正整数。用户明确指定的页数优先，保存后用于新任务。规划要点不等于海报行数，成品仍需检查是否清晰、放得下。

固定示例预览只检查排版，不调用文字模型；它不能代替真实生成后的内容核对。

04 · 图文转成讲解视频

  1. 在预览页点击“转成讲解视频”，或到视频编辑台选择已有图文。
  2. 检查章节、讲稿与逐句分镜。可调整导演预设、画面效果或为某句话上传自有图片；图表只使用原文数字。
  3. 先播放无声动态预览。画面确认后，再选择配音方式、声音、语速和讲解员，生成带配音的视频。
  4. 完成后下载 MP4、音频和字幕。在线语音、本机朗读和自己的语音 API 能力不同，使用语音 API 前检查配置与费用。

无声分镜预览不等于已完成配音；讲解员是系统提供的形象，不意味着复刻真人。

05 · 选择发布方式，再回填真实反馈

先打开发布与回访，选择自己需要的方式。发布方式与回访方式可以独立选择。

方式怎么操作
手动发布与回访到手动发布页选择内容和平台，下载成品、复制文案；本人到平台发布，回来登记实际作品链接或编号。选择对应作品，输入后台指标或导入报表。
抖音浏览器辅助到平台账号扫码连接官方后台，再到抖音发布与回访准备发布页。核对上传内容和平台设置后逐条确认提交。登录失效与平台验证由本人处理。

后台自动回访默认关闭；可以按需读取单作品数据，也可始终手动填写或导入报表和评论。数据未更新时留空，实际为零填0；填写实际观察时间。

准备素材、登记链接、确认作品、保存指标是不同动作。确认记录与当前内容对应，再到评论与复盘查看反馈，为下一篇提出调整。

06 · 内容不对，先定位哪一步

遇到的情况下一步
资料不足、网页打不开补充可读原文、公开来源或真实快照，再从预览页补资料重做。热榜标题和搜索摘要不能当作事实。
数量、页数、主题不对核对原要求与规划记录；在“内容再调整”明确写数量、页数及保留的信息，检查新版本。
事实或图片重点不对展开预览页的“资料与生成诊断”，逐项对照原文和图片主体；修改要求或对应题材 Skill。
引用编号、结构、排版错误查看制作任务的具体错误和执行履历，修复问题后再继续；失败记录保留，不应视为已通过。
模型调用结果未知先核查服务商记录和用量，不重复发送同一请求。没有确认结果时不能假装成功。
平台登录失效、数据尚未更新由本人重新登录或处理验证；等数据更新后回访，也可手动补录，不用零填充缺失值。

本教程介绍当前工作流。生成内容仍应由你检查；引用匹配证明转录一致，不证明源站事实可靠。教程不会自动生成、批准、发布或填入模拟指标。
