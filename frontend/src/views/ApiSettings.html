real 真实调用调用已配置的 Provider，按实际回传记账
fixture 契约演练不出网：用确定性合成响应跑通链路，结果不代表真实效果
local_seed 项目资料只用项目已有文档与素材，不调用任何 Provider

成本与限额

默认追踪实际消耗。金额上限可以留空——留空不等于 0 额度。
unknown结果未知：不写 0，先查状态不重发
estimated本地估算：与实测分开统计
provider_reported服务商回传：以回传为准
reconciled已对账：与账单核对后确认
金额未知 不等于 0 元。费用汇总里真实 / 演练 / 未知三类分开列示， 未知笔数单列待核实，不会被平均进总额。
