# 2026-10-09

## 1. 放开"只允许本机访问"（v1.4.1 → v1.4.2）
用户反馈：局域网/其它设备访问时前端显示「创作设置未读取：账号连接只允许本机访问」，工作台基本没法用，要求"删除全部这种相关限制"。

根因：`backend/app/api/accounts.py` 的 `local_request` 是**一个依赖挂 5 个 router**（`accounts` / `studio` / `content_skills` / `douyin_publishing` / `videos`），旧规则要求"客户端回环 + Host 是本机名"，非本机全 403 → 连 `/studio/options` 都读不到，前端只会显示上面那句话。看着像账号功能坏了，其实是整个应用。

改法（保留真正有意义的边界）：
- 非回环客户端**默认放行** —— 新增 `Settings.allow_remote_access`（`CWB_ALLOW_REMOTE_ACCESS`，默认 `true`）。能收到非本机请求本身就说明服务已被绑到可访问地址，再按客户端 IP 拦只是把内网访问打死。
- **Host 校验保留**（防 DNS rebinding）：本机名 ∪ `CWB_ALLOWED_HOSTS` ∪ 私有/回环/链路本地 **IP 字面量**。只放行 IP 字面量是刻意的——rebinding 必须借攻击者自己的域名。
- 同源（`Origin`）、拒 `Sec-Fetch-Site: cross-site`、写操作要 `X-CWB-Local-Action` 头，三条恒开。
- 想恢复旧行为：`CWB_ALLOW_REMOTE_ACCESS=false`。
