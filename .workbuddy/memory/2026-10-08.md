### 13) 修生产环境脚本报错：`crypto.randomUUID is not a function`（内网地址访问）
- **用户反馈**：生产环境打开后卡在"读取创作设置"。控制台：
  `Uncaught TypeError: crypto.randomUUID is not a function  at blank (direct-creator.js:3:30)  at setupDirectCreator (direct-creator.js:5:13)  at production.js:128:13`
  （另有一堆 `chrome-extension://…` 报错，那是用户自己装的浏览器扩展在本页注入失败，与本案无关。）
- **根因**：用 `http://内网IP:8000` 打开**不属于安全上下文**（`isSecureContext===false`）。此时 `crypto.randomUUID` / `navigator.clipboard` / `crypto.subtle` **根本不存在**，直接调用抛 TypeError。`setupDirectCreator()` 在模块体里调 `blank()` → 顶层 `await` 抛出 → 整个 `production.js` 后续代码不执行、`#creator-model` 永远停在"读取创作设置"。用 `localhost`/`127.0.0.1` 或 HTTPS 就没这问题（所以本地测试一直没暴露）。
- **修法（`frontend/src/assets/app.js` 新增兼容层）**：
  - `uuid()`：优先 `crypto.randomUUID()`；否则用 `crypto.getRandomValues`（**它不受安全上下文限制**）拼 16 字节并置 v4/变体位。**必须是合法 UUID**，因为后端 pydantic 把 `request_id` 声明为 `UUID`（`api/production.py` / `api/creation.py` / `api/content_skills.py`）。
  - `copyText(text)`：剪贴板不可用时退回 `textarea.select()+execCommand('copy')`；`canWriteClipboard()` 供调用方判断。
  - 6 个调用点全部改为走 `uuid()`：`direct-creator.js:3`、`template-library.js:49`、`video-studio.js:120`、`ReviewPreview.html:476/488/508`；`manual-publishing.js` 的复制改走 `copyText`。
  - `production.js:128` 把 `guide=await setupDirectCreator(...)` 包进 try/catch：失败时 `#creator-model` 写"创作设置未能载入"、`#creator-error` 给出可读原因 + 建议改用 localhost/HTTPS，其余页签照常可用（原来只会白屏/永远转圈）。
- **新增 6 条回归断言（`test_browser.py`）**：新开 context + `add_init_script` 删掉 `Crypto.prototype.randomUUID`、把 `navigator.clipboard` 置 undefined、`isSecureContext=false`。断言：① 模拟确实生效（`typeof crypto.randomUUID === 'undefined'`，防止后面的断言"因为环境是安全的"假过）② 创作设置能读出不卡住且无脚本异常 ③ `uuid()` 仍是合法 UUID v4 ④ 剪贴板不可用时 `copyText` 不抛错 ⑤ 预览页能加载并恢复调整入口 ⑥ 初始化抛错时给出可读原因 + 其他页签可用（用 `route.fulfill` 把创作模块换成"调用即抛错"的桩）。
- **踩坑**：第一次用 `route.abort()` 挡掉 `direct-creator.js` 来模拟失败 —— **模拟方式错了**。`production.js:2` 是**静态** import，模块加载失败会让 `production.js` 整个评估失败，`try/catch` 根本没机会跑（不可捕获）。用户实际的栈是"模块已加载、调用时抛错"，所以桩必须是"导出同名函数、调用时 throw"。另外用 `route` 时要在**全新 context** 里做，否则模块被 HTTP 缓存命中、route 不生效。
- **结果**：`browser` 阶段 108 → **116 通过 / 0 失败**。
- 顺便在 `README.md` 第 2 步写明：`http://内网IP:8000` 也能用，但一键复制等能力只在 localhost/HTTPS 下可用，其余情况自动退化成"帮你选中文本，请按 Ctrl+C"。

### 17) 局域网访问被拦：放宽 local_request（v1.4.2）
