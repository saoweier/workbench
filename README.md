# 内容工作台 v1.4.4

本地运行的抖音与小红书图文、讲解视频工作台。预设六组演示内容，配置模型后可制作自己的内容。

v1.4.4 修掉「**用机器名打开工作台会整个 403**」。第 4 条 Host 校验只认 IP 字面量和 `localhost`，用 `http://<机器名>:8000`（Windows 上很常见）访问时，机器名被当成外来域名拒掉，界面显示「创作设置未读取：请从本机工作台打开账号连接」。现在**本机自己的机器名（含短名与 `.local`）默认放行**——这些名字由本机/局域网解析决定，不是外部 DNS 能指过来的，放行它们不会给 DNS rebinding 开口子。同时：

- 被拒时 403 文案**直接写出当前 Host** 并给出该改哪个环境变量，不用再猜是哪条规则。
- `Origin` 校验只比 host:port，**不再比 http/https** —— 反向代理终止 TLS 时浏览器看到 `https`、应用看到 `http`，那不是跨站。
- 前端不再把 403 说成「服务暂不可用」：地址不被接受时如实显示服务端给的原因。

Host 校验**默认已全开**：`CWB_ALLOWED_HOSTS` 默认 `*`，任何 Host 都放行，用公网 IP、自有域名或反向代理域名访问都不会再被 403（此前 `47.96.185.149` 这类公网 IP 会被"只认 IP 字面量"的规则拦下）。要恢复严格的防 DNS rebinding 行为，把 `CWB_ALLOWED_HOSTS` 设成 `工作台.example.com` 这样的明确名单（留空表示"只认 IP 字面量与机器名"），那时外来域名、伪造 Host 的 DNS rebinding 会重新被挡下。无论哪种模式，`Origin` 同源校验、跨站请求拒绝、写操作必须带工作台自定义头这三条始终生效。

v1.4.3 让**局域网共享不再需要手动改命令**。此前启动脚本把界面写死绑在 `127.0.0.1` 上，同一网络里的手机或第二台电脑根本连不上，只能自己去翻命令行加参数。现在 `start.bat` 默认监听所有网卡，双击后终端会把可访问地址直接打出来（回环地址 + 本机内网地址，自动跳过 TUN/WSL 等虚拟网卡），照着输到另一台设备即可。只想自己用时加一个参数就恢复原样：

```
start.bat --host 127.0.0.1
```

也可以用环境变量 `CWB_HOST` 指定。**查询器（8091）仍然只绑回环**，它本来就是本机组件。`restart-api` 会沿用你启动时选的地址，不会偷偷退回只绑本机。

> **安全提醒（务必读）**：工作台**没有任何登录与鉴权**，默认监听所有网卡意味着同一网络里任何人都能打开。请只在你信任的网络里使用；要对外提供访问，必须在前面加反向代理 + 认证，或改用 `--host 127.0.0.1`。

v1.4.2 让**局域网/内网里其它设备**也能正常使用工作台。旧版把「账号连接 / 新建创作 / 创作技能 / 视频 / 抖音发布」这些接口限制成只有本机客户端能调，用 `http://内网IP:8000` 打开时会到处 403，界面显示「创作设置未读取：账号连接只允许本机访问」。现在非本机客户端**默认放行**。同源校验、拒跨站、写操作必须带工作台自定义头、Host 防 DNS rebinding 这几条防护全部保留。

要不要把这个边界也收回本机，由 `CWB_ALLOW_REMOTE_ACCESS` 决定：设 `false` 后接口层重新只服务本机客户端（仍需 `--host 127.0.0.1` 才能挡住连接）。

v1.4.1 修掉用内网地址访问时的脚本报错。用 `http://内网IP:8000` 打开不属于浏览器的安全上下文，`crypto.randomUUID` 等 API 本来就不存在，旧版会让「新建创作」一直停在"读取创作设置"；现在这些调用有等价实现，创作设置初始化失败也会显示可读原因而不是一直转圈。同时换掉前端资源的缓存版本号，避免浏览器继续使用旧模块。**如果你已经装过旧版，请按下面的步骤重新拉取。**

想自己复验上面两个场景，可以跑 `scripts/verify_insecure_origin.py`：它不带任何模拟，真的用非 localhost 地址打开页面，先确认该来源确实是"非安全上下文"、`crypto.randomUUID` 确实不存在，再验证创作设置能正常读出来、草稿 key 是合法 UUID、后端接受该 key，并直接点名 `/studio/options` 等受访问边界保护的接口。默认模式会起一套隔离服务（绑 `0.0.0.0`、独立临时库），不会写入你的业务数据。

```
.venv\Scripts\python.exe scripts\verify_insecure_origin.py
.venv\Scripts\python.exe scripts\verify_insecure_origin.py --origin http://10.6.101.1:8000
```

本版新增：技能入口说明、平台封面差异（小红书必须有封面、抖音可无）、榜单与导出专项验收、每次任务的交付物清单与路由用例表。演示样本的资料来源现在带可读正文，保存后即可在真实模式下走通"审核 → 批准 → 导出"，不会被防编造闸门拦下。另修掉预览页的一处竞态：详情还没读回来时「内容再调整 / 重新审核 / 生成图解」入口就已经可点，点下去只会弹一个瞬时提示、请求实际没发出去（看起来就是"点了没反应"），现在这些入口在内容就绪前保持禁用并写明原因。详见 [技能入口、专项验收与交付物清单](docs/SKILL_ROUTING_AND_ACCEPTANCE_20261008.md)。

## 直接使用

1. 双击项目文件夹内的 **start.bat**，它会启动界面与后台任务。首次没有运行环境时会自动安装依赖。
2. 打开 **http://127.0.0.1:8000/**。空库首次启动自动载入六组样本；已有业务数据保留。启动脚本默认监听所有网卡，终端会把可访问地址一并打印出来（回环地址 + 本机内网地址）—— 手机或同一网络的其它电脑直接输 `http://<本机内网地址>:8000/` 就能用；Windows 防火墙首次可能弹窗询问，选「允许专用网络」。只允许本机时用 `start.bat --host 127.0.0.1`（或设 `CWB_HOST=127.0.0.1`）。注意浏览器的「一键复制」等能力只在 `localhost` / `127.0.0.1` 或 HTTPS 下可用（这些地址才算安全上下文），其余情况复制按钮会自动退化成"帮你选中文本，请按 Ctrl+C"；工作台本身在非安全上下文下已做兼容，功能不受影响。
3. 在 **API 设置** 填名称、Base URL、模型名、API Key，并勾选已启用。支持 OpenAI 兼容文本接口：程序追加 `/chat/completions`，请按服务商要求填写包含 `/v1` 的地址。
4. 在 **内容生产** 从 **HotPush热榜选题**，或直接输入自己的题目。选信息密度、风格和页数，点 **开始制作**。原题、TOP数量、明确页数与时间范围会一路保留；不用填写受众、角度和提纲。热点聚合只读取HotPush公开接口，包含全部来源，显示实际更新时间、读取进度和失败状态；不会连接原平台账号。默认使用项目公开服务，可换成自建HotPush服务。草稿和后台任务可在刷新后恢复。
5. 在 **预览批准** 查看实际页图。**内容再调整**提供“更短更精简 / 更详细 / 更活跃 / 更精致”，也可写自定义要求；修改会生成新版本，保留原题、对象、数量与页数，旧版本可对照。榜单采用专用名次版式，可一页或两页列完整TOP10；不合要求的结果拒收或标记待调整，资料缺失不会改成另一个题目。需要真实配图时配置独立图片API或上传图片；文字模型不代替图片接口。按平台人工批准后才能导出发布包，新版本须重新批准。
6. 在 **图文转视频** 修改逐页讲稿，选中文 AI 配音和讲解员，生成带字幕的竖屏 MP4；可下载配音与字幕。默认使用自定义图片讲解员，可上传 PNG、JPEG、WebP（不超过 10 MB，边长 32–4096 像素），也可直接选择项目 `images/` 中的测试素材。图片保存在本机、保留透明背景与比例，在右下角静态展示；页面提供布局预览并记住所选图片。还可切换原版动画讲解员或仅图文与字幕。图片没有自动口型，声音单独选择。在线中文配音无需额外 Key；自己的语音 API 另行配置，不能直接使用文字模型代替。页内已有一份可直接播放的预置样片。
7. 在 **发布与回访** 选择操作方式。默认 **手动发布与回访**：准备素材，在官方平台本人发布，回来登记作品链接和实际指标。可选 **浏览器辅助发布**：先扫码连接自己的抖音账号，系统准备图文发布页，核对后由你逐条确认这一版再提交。视频目前通过手动入口上传。
8. **后台定时回访默认关闭**，可以在发布入口单独选择开启；单次回访可手动触发。平台没更新的数据留空，真实 0 填 0。**数据导入** 支持指标及评论 CSV/JSON；在 **评论与复盘** 生成报告，在 **反馈下一轮** 采用或回退建议。

首页根据实际配置、创作和发布登记提示下一步。**创作室**分为「新建创作 / 我的内容 / 制作任务 / 高级工具」。新建创作从「排行榜选题 / 自定义选题」两个入口开始，选定题目后进入「选择样式 → 确认制作」。工作台「打开教程目录」与各页顶部 **使用教程** 提供六段跟做教程：首次图文、手动发布回访、抖音浏览器辅助、模板与 Skill、讲解视频、失败诊断。支持定位控件、收起、退出、跳过和续看，核对当前版本和作品。封面、平台稿、榜单条目及高级工具按需载入。详见 [教程更新](docs/USER_GUIDE_20261006.md)、[应用内完整教程](http://127.0.0.1:8000/views/UserGuide.html) 与 [前端工作区改版](docs/FRONTEND_REDESIGN_20261005.md)。

保存配置不发起模型调用。已有配置点「编辑配置」，密钥留空会保留原密钥。默认追踪用量；未知费用为空，不设置金额上限也能运行有限任务。

### 动态讲解视频

图文转视频现在采用“选图文 → 看分镜、改讲解 → 选声音、生成”的编辑台。左侧切换章节，中间播放无声动态预览，右侧修改当前讲稿与逐句画面，底部生成按钮始终可见。内嵌 `video-director` skill 提供知识讲解、流程演示、对比分析三个预设；用户可为每句话选择效果或上传图片。导出包括 MP4、配音、字幕和带导演版本的分镜计划。页面提供 24 个分镜的动态样片，复用已有配音，播放不调用服务。

镜头与字幕按实际配音时长和句长估算，图片角色没有精确口型；数值图表只使用原文数据。详见 [动态视频使用说明](docs/MOTION_VIDEO_GUIDE_20261004.md) 与 [内嵌导演 skill](backend/app/skills/video-director/SKILL.md)。

### 接入自己的抖音账号

打开侧栏 **平台账号**，勾选「将抖音登录状态保存在这台电脑」，点击 **打开抖音，扫码连接**。系统打开工作台专用浏览器，你用抖音 App 扫描官方二维码并确认登录。进入后台首页后回来看连接状态，同时核对官方窗口里的昵称与账号。密码、验证码只在官方页面输入；浏览器安全提示、平台验证由本人处理。

选择浏览器辅助后，**抖音浏览器辅助发布与回访**会保存绑定账号、图片校验值和文案的发布任务。上传后核对编辑页和 AI 声明，再等你确认具体图文后提交；不确定的提交只回查，绝不自动重发。官方作品列表中的编号与标题核实后才产生真实发布登记。单作品页面可见指标以实际值入库，平台未更新或无法读取的指标保持缺失。仅有登录不会触发发布。

只在你明确点击单次回访或允许后台定时回访时读取数据；关闭连接窗口后，也可使用同一份本机登录状态执行已授权的只读回访。登录过期或平台验证会停止并要求本人重新连接。电脑关机、后台任务停止或平台页面变化时无法回访。当前已完成实际六图上传、文案回读和 AI 声明核对；首条正式发布与真实流量仍待用户确认和平台更新后验证，不能据本地测试称为线上闭环已完成。

关闭连接窗口保留本机状态，重新打开时再次验证；过期后需要重新扫码。普通浏览器的登录不会自动接入工作台。登录状态位于 `storage/platform_accounts/`，不通过 API 返回，也不进入项目交付包和默认备份；请勿分享或同步该目录。详见 [抖音连接与发布实测记录](docs/DOUYIN_CONNECTION_20261004.md)。

热点来自 [HotPush](https://github.com/JackyST0/hotpush) 的 `/api/hot/stream` 聚合接口，全部可用来源逐项载入。编号表示上游返回顺序，不把资讯流冒充全网热度排名；热度缺失留空。生活、科技、游戏为本地筛选，视频、影视、阅读、新闻按源分类。来源失败保留旧快照并显示时间，不用虚构热点替代。热点只能说明选题来源，不能代替文章事实依据。历史榜单（如上个月GitHub Skill TOP10）需要该自然月的真实统计资料，当前热点不证明历史热度。说明与实测见 [直接创作与HotPush接入](docs/DIRECT_CREATOR_20261004.md)。

七个流程技能分别负责热点发现、资料调研、题材确认、规划、生成、审核和改稿，另有科技与AI、生活与食养、游戏、新闻、职场、学习及通用内容七个题材技能。用户可在“内容团队”编辑这些要求并查看执行记录；每次任务冻结其使用的技能版本。

内容生产提供自动匹配及四种版式：**彩色排行卡片、分类速查表、图解手册、黑白编辑版**。点“查看示例”可直接看实际版式，不发起模型调用。排行卡片支持完整TOP10一到两页；分类表可集中列出最多16项，程序保证同类相邻。数据指标必须附可读来源及统计口径，无数据时留空。截图中的安装量不会当成真实资料。预览页可以持续调整内容、切换模板和题材技能，产生可对照的新版本；局部修改也会生成两平台独立页图，重新预览批准后才能发布。详见[题材技能与内容模板](docs/CONTENT_RECIPES_20261005.md)。


### 技能入口说明、专项验收与交付物清单

每个流程技能（热点发掘、资料调研、题材规划与确定、内容规划、内容生成、内容审核、内容再调整）在自己的 `SKILL.md` 顶部写着三问：**何时使用 / 需要输入 / 交给谁**。程序解析这三行并显示在“内容团队”的技能卡片上，所以“这个阶段什么时候用、要什么、交给谁”不用去猜提示词。入口说明与路由用例表 `backend/app/skills/content-team/evals.json` 同源：用例表逐条列出“用户说法 → 预期阶段、题材形态、数量约束、冻结模板与交付物”，由回归直接断言，修改路由时用例会先失败而不是悄悄走偏。

**平台差异在生成阶段就分开**：小红书必须有封面页且封面要给核心信息；抖音可以不做封面，第一页直接给实质内容。这条约定集中在 `backend/app/services/platform_policy.py` 一处，同时作用于生成提示词、平台稿校验、规则改写和榜单编译——不在 Skill 说明与代码里各写一份。抖音稿若出现多余的空封面，或小红书稿缺封面，都会被拒收。

容易出错的成品要求由程序判定，不采信模型自述（`backend/app/services/acceptance.py`）：

- **榜单专项**：名次版面存在、条目数等于用户要求、名次跨页连续不重复、对象互不重复、展示的指标必须与它所在的对象对应且同源。
- **渲染产物**：导出图片数量与页数一致、页序完整。少一张图就会被判为不可自动修复，交人工处理。

每次任务的**交付物清单**（`backend/app/services/deliverables.py`）逐项列出：来源快照、筛选记录、逐页卡片文案、视觉提示与图解类型、成品图数量、发布文案，外加上述专项验收结论。可在“内容团队 → 先查这条内容为什么这样写”查看，也会随发布包冻结进 `manifest.json` 与 `checklist.md`；数量对不上会在清单里标“未通过”，而不是让人自己翻目录。详见 [技能入口、专项验收与交付物清单](docs/SKILL_ROUTING_AND_ACCEPTANCE_20261008.md)。


## 预设成品

六组 **DEMO / fixture** 样本，共66张实际PNG。包含待审批、单平台批准、暂缓、6个发布ZIP、6条虚构发布登记、指标与匿名评论、2份复盘及建议回退记录。演示库存不占用真实内容待审额度。

每个演示样本的来源都带 `excerpt`（摘自 `examples/demo/source-notes.md` 的对应段落）并标注 `access_state=ok`、`excerpt_basis=local_file`。这样把演示内容标为真实模式后，批准与导出依赖的"可读证据"是真实存在的，闸门不需要为演示数据放宽。样本可用 `python scripts/seed_demo.py` 重建。

演示链接使用 `example.invalid`，指标与评论均为虚构数据，不能作为运营成效结论。项目保留 C001 素材，「一键出成品」可以再次制作离线基线。

## 安装、停止、备份

- 当前机器已准备独立运行环境。以后双击 `start.bat` 即可。
- 压缩包附 Windows 64位 Python 3.13 的离线依赖。其他机器需先安装 Python 3.11–3.13 和 Chrome/Edge；Python 3.13 可使用附带依赖离线安装，其他版本需联网安装依赖。
- `install.bat` 安装/修复，`stop.bat` 停止本项目，`test.bat` 执行隔离回归，不调用你的API、不修改你的业务库。
- 换端口可运行 `start.bat --port 8001`。
- 启动日志：`storage/logs/api.log`、`storage/logs/worker.log`。
- 备份：`.venv\Scripts\python scripts\backup.py`。
