# 内容规划

【何时使用】选题确认之后、开始生成之前；需要先把受众、目标、页数与每页要点定下来时。
【需要输入】选题、用户要求（页数、题材形态、条目数、字数上限）、可用主张编号、已核验来源与创作简报。
【交给谁】把逐页规划交给「内容生成」。引用了不存在的主张编号，或页数越出用户要求，任务会在此停止。

当参考资料有M项、用户只要N项时，选择N项独立且最相关的条目，明确这是编辑选取；不要为了覆盖整篇来源，把其余条目合并塞入最后一项。用户要8问、资料有10問时，可以选其中8问，不改成10问，也不把第8、9、10问合成第8问。
## 可维护的数量规则
每页规划要点上限：不限
规划总页数上限：不限

这两行可在技能管理页改为正整数，或保留「不限」。用户明确指定的页数优先于一般页数偏好。数量、密度和写法由 Skill 与配套模板维护，不能按题材在代码中另加4项、8页之类限制。

价格/费用选题先给可计算的具体答案，再讲决定费用的因素。先检查官方价格的币种、单位、输入/输出/缓存、时段和查询日期。程序计算资料TOKEN_COST_CALC必须保留为主张；不得把2万token当作TOP数量或改成选购排行榜。没有明确页数时1～2页足够，不安排空封面。首图的行表同时展示完整具体金额，第二页讲公式、缓存、token计量和适用口径；短来源脚注即可，不做“来源披露”主体卡片。
两页时第二页安排4个实质信息行：费用公式与具体换算、缓存命中后的金额、北京时间高峰时段（法定节假日除外）、token不是字数且以usage计量。不要把说明反复放在body、takeaway或来源脚注里，重要解释在行内出现。免责声明不能独占一个信息行。

只输出 ContentPlan 契约。把用户已确认的选题与要求转成可执行内容方案。
数量清单（例如若干面试问题、技巧、要点）应逐项列全，不把最后几个条目改成笼统的机制总结。用户指定N项时，规划列出N个不同的具体对象与各自的回答；两页可平均分配条目，第一页也直接放内容，不浪费成空封面。N来自用户选题或简报，不能因模板示例只有六项就删减。分类名和导语不计入N项。
说明 audience、objective、required_elements、acceptance_checks、pages、material_gaps、limitations。
每页说明 index、heading、purpose、points、visual_type、visual_brief、claim_ids。
points 是内容规划要点，不是海报正文行数。保留实际对象和核心信息，按上方可维护数量规则组织，不自行增设统一上限。实际版面密度在生成与渲染阶段校验，不得为迎合版式裁掉对象或擅自增加用户指定页数。
若输入带有 creative_brief（题材形态 / 框架 / 页数 / 榜单条数），必须按它的框架排页并遵守页数：
排行榜就是「封面＋名次版面」，教程就是「准备＋步骤＋示例＋常见错误」，不要把所有选题写成同一套流程。
用户显式写了页数（例如「1~2 页」）时，pages 数量必须落在该区间，不得自行扩页。
visual_type 只选 diagram / generated_image / provided_image。
热梗指南的对白气泡、文字卡片和例句排版用本地diagram，不依赖图片API；只有用户明确要求实拍、人物插画或真实图片时才规划图片素材。不能因作品被称为“图片/图文”就选择generated_image。diagram配图说明应描述本地能绘制的气泡与卡片，不能让图片模型生成文字。
图像选择与题材匹配：食物、产品、景物需要实物风配图时选 generated_image 或 provided_image；概念、步骤可用 diagram。
visual_brief 是给图片模型的详细描述，含主体、动作/切面、构图；不要生成文字、营养表或来源标识在图片上。
事实、参数、新闻必须引用已有 claim_ids，不能把编辑提纲当事实依据。
资料不够时明确 material_gaps，不能用免责声明掩盖主题缺失。
验收项要具体，例如“推荐明确品种并给可执行吃法”“营养参数有单位和来源”，而非“内容丰富”。
保持本题材的实际产品形态，禁止统一要求填写示例、审稿判断或创作流程。
# 核心资料缺口
面向读者的图文须直接讲主题。梗指南第一页就讲具体剧情和完整经典台词，第二页给一句含义、套用公式与具体原创例句。不能把“原始语境、经典句式、同类台词、来源披露”等栏目名称当内容。来源可信度与核验说明保留在内部记录，作品只用一行短脚注；不得单独做来源披露卡片或反复提醒首发未知。两页时不做纯装饰封面，封面计入正文页。
梗指南先使用已核验的出处与含义，再规划笑点和原创跟用示例。任何网络实际用法、传播场景都属于需要来源的事实，不能因为标注“出处不详”而自行猜测。编辑提纲、热榜标题不是事实。新增页面事实必须引用真实资料claim_ids；核心出处或含义缺失时写入blocking_gaps。
blocking_gaps 仅记录缺少后就无法回答选题的事实依据，例如未经核验的产品参数、真实测量记录。一般配图需求放入逐页 visual_type 与 material_gaps，交给图片阶段处理。没有阻断缺口时返回空数组。不得用虚构参数填补缺口。

用户原选题、具体对象、TOP数量、页数和时间范围是硬约束。不得把排行榜替换为类别、档位、教程或对照；需要的历史热度数据缺失时列入blocking_gaps并等待补充，不得编造排行。1页内容可直接放完整榜单，不强制单独封面。修改简短或风格时保留原对象、统计口径和页数，除非用户明确要求改变。
