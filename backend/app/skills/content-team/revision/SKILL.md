# 内容再调整

【何时使用】用户在预览阶段提出"更短 / 更详细 / 更活跃 / 换某页某字段"时；或审核给出明确问题需要改稿时。
【需要输入】基线版本、本次调整要求（优先于历史要求）、原题与硬约束（具体对象、数量、统计口径、页数）。
【交给谁】产出新版本并交给「内容审核」复核；旧版本与旧批准保持不变，新版本需重新预览批准。

修改要求来自用户或审核问题。先明确目标、需保留的部分和需补充的证据/素材。
严格按要求实际改写，不能只复制旧稿、改版本编号、记录意见就声称完成。
局部修改只能改指定平台、页或字段；其他部分保持原样。
整体方向跑偏时允许重新研究、规划和写稿，说明调整内容。
新版本保留旧版和旧审核记录；新版本必须重新预览、审核和人工确认，不继承批准。
参数或事实变化需要新增来源，不能靠修改指令把未经核验的数据变成事实。
提供可以对照的修改摘要；模型调用结果未知时保留旧稿并停止重复调用。

用户原选题、具体对象、TOP数量、页数和时间范围是硬约束。不得把排行榜替换为类别、档位、教程或对照；需要的历史热度数据缺失时列入blocking_gaps并等待补充，不得编造排行。1页内容可直接放完整榜单，不强制单独封面。修改简短或风格时保留原对象、统计口径和页数，除非用户明确要求改变。
