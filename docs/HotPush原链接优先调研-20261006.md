# HotPush 原链接优先调研

## 调研顺序

**热榜选题：原题与原链接 → 读取原页 → 模型判断资料是否足够 → 按具体缺口补充搜索 → 组织内容。**

**自定义选题：没有原链接时，从已配置的 SearXNG 搜索开始。**

HotPush 已携带 `title` 与 `url`。旧实现对知乎、抖音等域名整体排除，把“不能抓平台热榜”扩展成了“不能读取选中的原题页面”。本轮取消这个选中页面的排除，仍只通过 HotPush 获取热榜。

工作台读取公开原页，然后把原题、原地址、正文、读取状态与哈希提供给模型。不会假定一个普通文字模型收到网址就能访问它。题目、简介、来源排名保留为线索，不升级成正文证据。

原链接被拒绝、返回登录/验证页、没有回答或核心资料不足时，保留失败记录，使用 SearXNG 及现有备用入口补充。补充轮数由资料调研 Skill 维护。不借用已登录平台账号绕过限制，不自动发布。

## 界面与留存

- 确认制作页显示“热榜原题来源”和“查看议题原链接”。
- 修改选题措辞仍保留所选原链接；切换到自定义选题会取消该关联。
- 后台按已选条目冻结原题、地址、更新时间与快照。
- 诊断中保留 `read_selected_topic`、原地址、跳转后地址、读取结果、正文长度及实际补充检索。
- 没有额外搜索时，预览显示“已读取热榜原链接，未执行补充搜索”。
- 改稿可沿用冻结正文；不会把旧来源冒称为重新检索。

## 真实浏览器验证：C049

## 回归

新增 `hotpush_research` 23 项检查，覆盖原链接保留、所选平台议题页读取、正文与地址进入后续输入、原文足够不搜索、明确缺口补充搜索、403 自动备用、缺链接、自定义选题、冻结来源复用、非公开网络拒绝与畸形旧快照。

旧 `evidence_grounding` 测试中“所选平台原链接必须排除”的预期与新需求冲突，更新为验证各类原链接均进入冻结元数据，同时保留快照不能代替正文的检查。

最终选取 **10 组相关回归，561 项通过，0 项失败**，不是项目所有测试组。预览页检查没有捕获脚本错误。完整日志：[regression-final.log](test-artifacts/hotpush-origin-first-20261006/regression-final.log)。

原链接优先可以减少搜索歧义和不必要调用，但链接仍可能失效、被限制或内容与标题不符；程序应根据读到的正文与具体缺口选择补充资料，不能保证每个链接都可访问或每个话题都能获得充分证据。
