# 内容工作台 v1.0.1

本地运行的抖音与小红书图文工作台。预设六组演示内容，配置模型后可制作自己的内容。

**新版教程（2026-10-06）**：工作台点击「打开教程目录」，或任意页面顶部点击「使用教程」。六个教程分别介绍首次图文、手动发布回访、抖音浏览器辅助、模板与 Skill、视频、失败诊断。首次图文教程包含内容再调整。按需要选择，可收起、跳过、续看和重新打开。也可直接打开 [完整使用教程](http://127.0.0.1:8000/views/UserGuide.html)。

## 直接使用

1. 双击项目文件夹内的 **start.bat**，它会启动界面与后台任务。首次没有运行环境时会自动安装依赖。
2. 打开 **http://127.0.0.1:8000/**。空库首次启动自动载入六组样本；已有业务数据保留。启动脚本默认监听所有网卡，终端会打印可访问地址：手机或同一网络的其它电脑输 `http://<本机内网地址>:8000/` 即可使用，用 `http://<机器名>:8000/` 也可以（Windows 防火墙首次弹窗请选「允许专用网络」）。**工作台没有登录与鉴权，默认监听等于同网段谁都能打开**，只在自己用时加 `--host 127.0.0.1`。
3. 在 **API 设置** 填名称、Base URL、模型名、API Key，并勾选已启用。支持 OpenAI 兼容文本接口：程序追加 `/chat/completions`，请按服务商要求填写包含 `/v1` 的地址。
4. 在 **内容生产** 从Hotpush热榜选题，或直接输入自己的题目，再选择信息密度、风格和海报样式、补充要求并确认生成。系统自动建批次并排队，完成后打开预览继续调整。现有五套海报都有实际样式预览，规则与外观可在 **样式工坊** 维护；参见 [海报模板说明](TEMPLATE_POSTERS_20261006.md)。草稿自动保存在当前浏览器。
5. 在 **预览批准** 查看实际页图，按平台分别批准，导出相应 ZIP。修改后的版本需要重新批准。
6. 本人手动发布后到 **发布记录** 登记链接/作品ID和时间。**数据导入** 支持指标及评论 CSV/JSON、粘贴或文件上传；真实文件选择「真实数据」。在 **评论与复盘** 生成报告，再在 **反馈下一轮** 采用或回退建议。

保存配置不发起模型调用。已有配置点「编辑配置」，密钥留空会保留原密钥。默认追踪用量；未知费用为空，不设置金额上限也能运行有限任务。

## 预设成品

六组 **DEMO / fixture** 样本，共66张实际PNG。包含待审批、单平台批准、暂缓、6个发布ZIP、6条虚构发布登记、指标与匿名评论、2份复盘及建议回退记录。演示库存不占用真实内容待审额度。

演示链接使用 `example.invalid`，指标与评论均为虚构数据，不能作为运营成效结论。项目保留 C001 素材，「一键出成品」可以再次制作离线基线。

## 安装、停止、备份

- 当前机器已准备独立运行环境。以后双击 `start.bat` 即可。
- 压缩包附 Windows 64位 Python 3.13 的离线依赖。其他机器需先安装 Python 3.11–3.13 和 Chrome/Edge；Python 3.13 可使用附带依赖离线安装，其他版本需联网安装依赖。
- `install.bat` 安装/修复，`stop.bat` 停止本项目，`test.bat` 执行隔离回归，不调用你的API、不修改你的业务库。
- 换端口可运行 `start.bat --port 8001`。改监听地址用 `start.bat --host 127.0.0.1`（只本机）或 `--host 0.0.0.0`（默认，局域网可访问），也可设环境变量 `CWB_HOST`。`restart-api` 会沿用启动时的地址。
- 用自己的域名或反向代理访问时，把域名写进环境变量 `CWB_ALLOWED_HOSTS`（逗号分隔），否则会被防 DNS rebinding 的 Host 校验拦下；拦下时的 403 会写明当前地址。
- 启动日志：`storage/logs/api.log`、`storage/logs/worker.log`。
- 备份：`.venv\Scripts\python scripts\backup.py`。
- 恢复：先 `stop.bat`，再 `.venv\Scripts\python scripts\restore.py <备份文件>`。恢复前自动保留快照；备份排除密钥，换机器请重新配置。
- Unix：建立 `.venv`、安装 `requirements.txt`，使用 `scripts/start.sh` 与 `scripts/stop.sh`。

查看 [测试报告](TEST_REPORT.md) 与 [计划对照](DELIVERY.md)。真实模型质量、平台上传兼容性与真实传播效果在用户接入后验收。
