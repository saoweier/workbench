# C018 图片内容修复

用户反馈图片重复来源和核验说明，核心内容没有展开。已确认两个根因：旧封面模板只绘制标签，不绘制对应detail；模型审核只看到整个JSON和发布文案，没有单独对照模板实际展示的文字。

## 工作台规则与模板

- 更新规划、生成、审核技能，图片须独立解答，第一张也是内容页。详情必须展开，不能依赖发布caption补足。
- 新增梗指南模板 `meme-guide-*@2`，显示全部台词、剧情、含义和例句详情；去掉通用办公插画和空白品牌装饰。
- 图片主体禁止来源披露卡片，来源核验提醒占主体超过20%时阻断。
- 梗指南不重复绘制补充总结段落，整个作品只在第一张保留一行来源脚注。空脚注不会被默认“方法图解”说明补回来。
- 审核输入包含模板实际展示的主体文字投影，明确与发布caption分开检查。这是文字检查，不声称模型看过像素。
- 支持本地图片精简的新版本接口。保留全部主体详情、文案、证据和旧版本；重复请求幂等，新版不继承批准。
- 梗指南本地气泡与卡片使用diagram；创作和重做接口支持显式 `image_policy=diagram`，不用为文字排版购买图片生成。

## 实际结果

当前C018为V5，抖音、小红书各两页。第一页包含经典对白、剧情套路、笑点；第二页包含实际用法、套用公式和三个原创例句。旧V1～V4及其产物全部保留，当前待人工预览，未批准、未发布。

V3已通过生产、渲染并生成真实图片，但模型审核提出重复信息问题。随后V4/V5由本地精简和模板升级创建，没有再次调用内容生成模型。

额外模型复审返回格式不合格（摘要超长），还包含引号、引用编号等自相矛盾判断；原始返回保留在诊断页，**没有计为模型审核通过**。程序与浏览器检查通过不等同于语义审核通过。

相关回归：37项图片检查、39项既有图解检查、63项事实与技能诊断检查，共139项通过。实际V5的只读检查另存 `docs/test-artifacts/meme-image-quality-20261006/final-verification.json`，涵盖真实PNG哈希、详情完整显示、两页约束、仅一行脚注、无通用装饰及预览页面。
