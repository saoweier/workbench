# 视频、发布方式与上手教程

2026-10-04，内容工作台 v1.1.0。

## 图文转成讲解视频

1. 在预览页点击「把这份图文转成讲解视频」，或者进入侧栏「图文转视频」。选择已经出图的当前版本。
2. 默认填入逐页短版讲稿；点击「填入完整讲解」会加入图解中的标签与说明。按钮会替换当前讲稿，之后可以逐页修改。
3. 选择声音、语速和是否显示动画讲解员。在线中文 AI 配音提供晓晓女声、云希男声，需要联网，无需额外 API Key；自己的语音 API 单独配置，文字模型不能当语音模型用。本机系统朗读属于明确标注的离线选项，不是 AI 服务。
4. 在线方式需勾选发送讲稿的确认项，再点击生成。后台逐页配音、合并音频、烧录字幕并编码 MP4。页面更新任务状态，不刷新讲稿、不打断已完成视频的播放。
5. 完成后可以播放或下载视频、WAV 配音及 SRT 字幕。视频为 720×1280、H.264/AAC、12fps。字幕时间按照段落时长估算，不是逐字对齐；原创动画讲解员有眨眼、嘴部和手势动作，不是真人数字人，也不是精确口型同步。

自己的语音服务需支持 OpenAI 兼容 `/audio/speech`，填写基础地址、语音模型和服务支持的声音名称。保存配置不调用服务，密钥不回显。外部语音服务使用 HTTPS，本机 HTTP 服务需明确允许；重定向不跟随。供应商账单未提供时费用保持未知，不写成免费或 0。

同一提交重复点击会复用任务；修改讲稿或选项会生成新的提交编号。图文版本及页图校验值绑定到视频任务，缺图或文件变动会停止。失败、结果未知和中断不会自动再次调用配音；确认取消后，在当前调用或渲染检查点停止，已经执行的调用不能撤销。音频与视频文件完成后才开放下载。

视频页附一份预置的 92 秒 AI 配音样片，首次安装也能直接播放，不调用文字模型或配音服务。它来自真实 C009 生成，作为产品输出样例，不代表平台发布成果。

在线配音实现依据：[edge-tts 项目](https://github.com/rany2/edge-tts)；自有语音 API 的请求结构依据：[OpenAI Audio speech 接口](https://platform.openai.com/docs/api-reference/audio/createSpeech)。在线服务的可用性由其提供方决定；失败会显示实际状态，不会悄悄换成另一种声音。

## 手动与浏览器辅助分开

「发布与回访」提供两个独立入口，默认**手动发布**；定时后台回访默认关闭。

| 方式 | 系统做什么 | 用户做什么 |
|---|---|---|
| 手动发布与回访 | 整理图片、正文与视频；登记人工发布信息；保存手填或导入的指标、评论 | 本人在官方平台上传并发布；回来填写实际作品链接、实际数据 |
| 抖音浏览器辅助 | 用专用登录窗口准备图文发布页；确认后提交这一版；按需核实作品及读取可见指标 | 扫码登录、处理平台验证；核对账号、图文、AI 声明、公开范围与时间；逐条确认提交 |

手动入口只提供真实生成的稿件，演示素材可在预览中查看。图片包沿用预览批准与版本校验，视频在视频页下载。手动登记须勾选已实际发布，登记仍是「人工声明」，不会伪造为系统已核验成功。

手动回访选择真实作品、查看时间与流量来源，填写平台实际值；空白不补零，实际 0 保留为 0。同一回访再次提交会去重。保存结果明确显示接受、重复、异常与待匹配数量。评论和平台报表可从数据导入页导入，继续进入复盘与反馈下一轮。

选择手动后，浏览器上传、确认发布及已排队的提交均暂停。选择辅助不等于批准任何新稿件，也不等于允许定时回访。单次「核实作品并回访数据」可以独立执行；若要周期读取，须另外勾选并保存后台回访许可。登录过期或平台验证时停止并由本人处理。辅助发布当前支持图文；生成的视频通过手动入口上传。

当前 C009 已保留图文和视频，没有正式提交到抖音。旧的发布准备改为需要重新准备编辑页，避免把已关闭窗口中的旧确认当成可提交状态。数据中心预期更新时间来自用户提供的提示；真实发布、作品字段和流量仍需实际平台验证。
