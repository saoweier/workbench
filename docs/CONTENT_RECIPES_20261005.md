# 题材技能与内容模板（v1.3.0）

## 怎么使用

1. 内容生产：从HotPush选择题目，或直接输入自己的题目。
2. 选信息密度、风格、页数。题材方向和模板可以自动匹配，也可自己选择。
3. 先看模板示例，再点开始制作。示例是本地排版演示，没有真实热度或安装量，查看不调用模型。
4. 预览批准：查看实际页图、资料、规划、技能履历与审核意见。
5. 内容再调整：选择更短、更详细、更活跃、更精致，或写自定义要求；可以同时切换模板、题材技能。新旧版本保留并可对照。
6. 局部标题、正文修改只改变指定文字，但新版本会生成两平台独立页图。所有新版本均需重新批准，不继承旧版批准。

## 技能分工

| 层次 | 职责 |
|---|---|
| 热点发现 | HotPush来源与更新时间；不把资讯流冒充热度榜 |
| 调研核验 | 保存来源、事实、缺口与限制，明确排名统计口径 |
| 题材确认 | 保留用户题目、具体对象、数量、时间范围与输出形式 |
| 内容规划 | 页面目的、信息结构、配图和验收条件 |
| 内容生成 | 输出结构化文字数据；程序负责名次、分页和版式 |
| 内容审核 | 核对原要求、完整资料和程序实测页数、字数、对象序列 |
| 内容再调整 | 按要求生成新版本，保留事实及硬性要求 |

另有七个题材技能：科技与AI、生活与食养、游戏、新闻与热点、职场办公、学习知识、通用内容。科技技能要求名称、版本及热度统计可追溯；生活技能要求具体推荐、吃法及带来源单位的营养数据；其他方向分别约束版本、时间线、实际步骤和案例。

“内容团队”提供14个独立编辑器。任务开始时冻结七个流程技能和当前题材技能的版本；后续修改规则只影响新任务。技能定义不能给予模型读取密钥、批准内容或发布的权限。

## 四种可选模板

| 模板 | 内容与约束 |
|---|---|
| 彩色排行卡片 | 名次、图标、用途、短标签；支持完整TOP1–TOP12，指标须有来源 |
| 分类速查表 | 分类色块、名称、主要功能，最多16项；同类由程序聚合，无名次 |
| 图解手册 | 关系图、流程、对比、具体示例与配图 |
| 黑白编辑版 | 清晰文字层次与少量重点色，适用于不同题型 |

用户要求TOP10时不能静默改成分类表；不兼容的组合明确提示调整选择。首页排版标识不额外增加封面。分类表和排行文字由模型填写，程序拥有数量、分组、名次、分页、图标及HTML。所有文字转义后进入模板。

真实分类内容中，每个具体对象必须出现在可读资料里。显示指标需要指标名称、来源引用、原始数值及统计口径；名称与数值必须出现在同一条原始记录中。这里验证的是数据转录一致性，来源的真实性仍需核验。缺失指标留空，不以0代替。参考截图仅作为设计样式，不作为下载量等事实依据。

## 恢复和审核

模型审核收到完整来源及程序实测值，禁止估算已提供的字数或把首图误判为额外一页。审核只给意见，不代替人工批准。已发现并保留模型误报记录，不声称每次语义审核都正确。

审核响应中的已知空格式附注可规范化；其他未知字段或权限字段严格拒绝。原始服务响应保留。一次任务在新稿保存后审核中断，显式重试可使用本任务检查点恢复；不能覆盖其他任务的新版本，不能越过批准或发布状态，已完成模型调用不会重复请求。
