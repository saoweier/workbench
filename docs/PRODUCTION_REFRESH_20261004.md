# 内容生产页面自动刷新修复

日期：2026-10-04。

## 原因与复现

原页面每五秒调用完整 `load()`，无论是否有执行中的任务，都替换内容表和任务列表，再逐条异步读取平台稿。平台稿短暂显示“读取中”，行高、滚动位置及按钮焦点可能变化；日志也反复新增同一条统计。异步详情读取未等待结束，慢请求时可能重叠。

修复前，隔离浏览器测试在观察 6.2 秒后失败：`AssertionError: 空闲时停止五秒自动刷新`。实际工作页面没有运行中的任务，但日志每五秒持续增长。

## 修复

- 只有排队中或运行中的任务触发五秒进度更新；任务完成或暂停后停止。重新进入可见页面时检查一次，另保留手动刷新。
- 根据内容与任务 ID 保留原有节点；只修改变化的单元格或任务记录，没有变化时不重绘。
- 等待详情请求结束后一次提交完整结果，不插入临时“读取中”行。
- 请求串行，下一次更新从上一次完成后计时；读取期间禁用手动刷新按钮。
- 保留表单、已有批次、滚动位置及可继续操作的按钮焦点；日志只记录操作，不重复刷统计。
- 列表读取失败保留现有清单；单条详情失败保留原平台稿并明确提示，恢复后正常更新。
- 使用列表事件委托，避免每次读取重复绑定按钮或写入过期详情。

空闲时其他页面或其他窗口新增的任务，不再由本页持续轮询发现。可点“刷新”查看，或返回此页面时自动检查一次。
