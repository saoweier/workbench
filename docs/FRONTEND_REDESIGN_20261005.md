# 创作工作区改版 · 2026-10-05

## 使用方式

- 首页显示实际工作区状态和建议的下一步，演示作品不计入创作进度。
- **创作室 → 新建创作**：首屏从「排行榜选题」或「自定义选题」开始。排行榜先浏览各来源榜单、点选题目；自定义先输入题目。两条路径选定后汇合到「选择样式 → 确认制作」。每步只显示当前需要的设置，右侧摘要同步变化。手机将流程收拢为单列。
- **我的内容**：搜索、按状态筛选、分批查看。每行可以勾选，表头全选当前显示条目；「选择全部筛选结果」可包含尚未展示的条目。点「批量清理」后确认数量，再显示执行进度。失败条目保留勾选并说明原因，可重试；切换搜索或状态会清空选择。清理沿用原丢弃接口，任何内容状态均允许清理，包括已有发布登记的内容。未完成的图文制作任务会停止，审核、调用与发布记录保留，平台上的作品保持原状。点「加载平台稿」才读取该条详情，点「打开成品」进入预览修改。
- **制作任务**：查看真实任务进度，暂停、继续、取消或修复后重试。执行期间更新，空闲或页面隐藏时停止持续读取。
- **高级工具**：离线演示、批次生产和诊断日志保留在独立入口，进入后才载入代码、表单和素材列表。
- 首页和创作室的 **操作指引** 会带到实际页面、高亮控件并核对完成状态。可以收起、退出、重开或明确跳过；跳过不会被记为完成。

## 加载与动态效果

创作表单先读取创作配置，不等待内容清单、全部详情和历史任务。首页取消逐条复盘请求，封面详情用 IntersectionObserver 在接近视野时读取，最多三个并发；图片使用原生 lazy loading 和异步解码。排行榜只在选择该入口后读取，通过可直接点击的「榜单来源」筛选按钮一次显示一个来源，选中来源高亮，不使用下拉框，每页六条，用上一页、下一页浏览全部条目。取消榜单内外两层滚动；选题入口在浏览榜单时收紧为短按钮，来源说明和更新时间按需展开，热点服务设置保持隐藏。刷新恢复所选来源、页码与题目。

配置读取、列表读取和封面读取分别提供加载反馈。页面与步骤使用轻量入场过渡，制作显示真实阶段状态，慢请求在顶边提供状态动画。尊重系统的减少动态效果偏好。加载失败说明原因并提供重试；内容库刷新失败保留已有列表。

## 保留的行为

没有更换后端协议、引入打包框架或额外在线字体依赖。原题、要求、资料、配图、题材、模板、页数与平台继续进入原制作接口。原本的浏览器草稿键保留，已有任务可恢复；任务设置只读，通过「写下一篇」重新启用输入。制作仍需本人确认，平台发布的确认规则保留。

侧栏将常用创作、发布与反馈入口集中展示，账号、导入、发布记录、技能和用量进入可展开分组。所有原页面仍可从导航或搜索进入。

## 验证

新增隔离的 `test_frontend_workflow.py`，由原 `production_refresh` 测试入口运行。覆盖两个选题入口、榜单按需读取、来源切换、分页边界、空来源、刷新恢复、取消嵌套滚动、表单校验、完整提交参数、草稿与任务恢复、任务控制、按需详情、分页筛选、刷新失败、动态引导、手机布局、诊断失败反馈、减少动态效果和批量清理（选择范围、取消确认、部分失败重试、空列表），最新 57 项通过。清理验证只操作隔离的测试数据。

原端到端、技能、版式和视频测试已迁移到新入口和三步流程。所有验证使用隔离数据库与本地模拟接口，不调用用户模型，不写入业务数据。截图和新流程结果位于 `docs/frontend-verification/`；原端到端证据继续写入 `docs/test-artifacts/`。

2026-10-06 初次改版验收结果：`production_refresh` 36 项、`browser` 104 项、`content_skills` 59 项、`content_recipes` 61 项、`studio_updates` 109 项，共 369 项通过。随后针对榜单来源切换与分页调整复测 `production_refresh`，43 项通过；加入批量清理后再次复测，57 项通过。回归时补齐了改稿请求漏定义的 `image_policy` 字段，默认行为保持兼容；诊断初始化也使用已有错误保护，在读取失败或快速切页时显示原因，避免未处理异常。

## 清理规则调整 · 2026-10-06

取消已有发布记录时返回 `409 STATE_CONFLICT` 的限制，单条和批量清理沿用相同请求与响应。`discarded` 保持终态：内容状态更新在数据库中检查终态，旧会话、取消回调、失败回调以及平台审核聚合都无法将其恢复到默认内容列表。重复清理继续保持幂等，历史发布记录及其外键引用完整保留。

验证使用隔离数据库：`test_discard_lifecycle.py` 27 项、`test_p2_e2e.py` 88 项、`test_p3_e2e.py` 199 项、`production_refresh` 57 项，共 371 项通过，未操作用户真实内容。
