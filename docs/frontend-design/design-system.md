# 设计系统

变量定义于 `frontend/src/assets/tokens.css`，排版与动效分别在 `typography.css` 和 `motion.css`。

- 背景 `#f7f8fa`，表面白色，文字 `#202530`，次文字 `#707886`。
- 强调蓝 `#1768ef`，搭配橙 `#ec834d` 与绿 `#258b70`；状态采用浅底标签。
- 空间级别4/8/12/16/24/32/48px；圆角8/12/20px及状态胶囊。
- 侧栏216px；内容最大1220px；桌面内边距36px，手机18px。
- 输入框40px，按钮40px，键盘焦点3px浅蓝描边。
- 图卡轻阴影，表格与表单弱边框；页面模块避免全部使用同样卡片。
- 悬停160ms、位移2px以内；尊重减少动态效果设置。
