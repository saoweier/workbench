# 参考截图设计解构

参考为用户提供的 SchoolAI 页面截图。提取内层产品界面：浅灰背景、窄侧栏、上方搜索、蓝色主按钮、宽幅插画封面、图片内容卡片及大块留白。外层截图网站的模态窗口与灰色遮罩不属于目标工作台。

设计气质：轻松、创作感、清晰而友好。侧栏约占产品宽度15%；封面约3:1；导航使用细线图标与浅色选中背景。内容卡片为白底、约12px圆角、轻阴影，图片承担色彩和第一视觉焦点。

迁移：宽幅原创工作室插画用于首页；现有成品页图用于真实内容卡；少量蓝/橙/绿用于图标底色与业务状态。桌面侧栏216px、内容最大1220px；768px及以下侧栏抽屉化，卡片重排。字体使用本机中文无衬线，标题28–34px，正文14px。

只迁移布局与组件语言，不复用参考的品牌、Logo、人物插画和文案。封面不影响模板页图及发布产物。
