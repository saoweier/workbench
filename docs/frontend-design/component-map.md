# 组件映射与接入

| 参考元素 | 项目元素 | 数据与交互 |
|---|---|---|
| 左侧导航 | app.js 的 navBar + 图标函数 | 原十个页面地址，分组、当前页、手机展开/关闭 |
| 顶部搜索 | 共享页头与搜索弹层 | 搜索实际页面及 `/contents` 数据；点击导航到实际内容 |
| 大幅封面 | 首页 feature-hero | 原创插画；真实内容生产入口与离线制作按钮 |
| 最近查看卡片 | 首页 content-gallery | 实际内容详情与首张产物，不用空白假缩略图 |
| 活动卡片 | 首页三个工作入口 | 生产、审批、复盘及实际链接 |
| 表单与列表 | 原业务页面组件 | 共享视觉升级，接口和版本机制保持 |

视觉层先定义静态外壳、封面和图卡结构，再将真实内容与现有动作接入，避免在视觉原型阶段修改后端。手机采用单列封面、两列图卡（最窄单列）与抽屉导航。
