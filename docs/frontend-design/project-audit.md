# 界面改版：项目理解

现有前端为原生 HTML 与 ES 模块，共十个业务页面；后端直接托管 `/assets` 和 `/views`。共享样式为 `frontend/src/assets/app.css`，导航、状态与数据格式由 `app.js` 提供。页面有少量内联样式，表单和页图区域可沿用。

主要问题：横向导航拥挤；首页说明文字过多；成品藏在表格与页面底部；卡片缺少图片和视觉层次；字号偏小。此次调整共享外壳、设计变量与首页信息顺序，业务页面统一表单、表格、页图卡片和按钮。

实施风险：导航替换不能改变已有地址；动态成品卡必须绑定真实内容ID；窄屏需折叠侧栏并限制表格溢出；所有动作继续调用现有业务接口。
