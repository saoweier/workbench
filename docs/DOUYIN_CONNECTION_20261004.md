# 抖音连接、发布与回访 · 2026-10-04

## 用户操作

1. 工作台侧栏「平台账号」。
2. 勾选本机保存登录状态说明，点击「打开抖音，扫码连接」。
3. 在独立浏览器内，用抖音 App 扫描官方二维码，在手机核对账号并确认。
4. 进入创作者后台首页，回到工作台查看状态。请核对官方窗口中的账号昵称。
5. 到「抖音发布与回访」选择真实成品，建立准备并上传图文；核对后确认这一版正式发布。
6. 系统核实官方作品编号后登记，审核状态与可见指标分别记录。未更新指标保留缺失。

官方入口：<https://creator.douyin.com/>。登录、平台条款及验证码由用户本人处理。

## 当前交付范围

- 专用持久浏览器目录，兼容项目 Chromium 与本机 Chrome/Edge 解析方式。
- 固定官方 URL；不接受任意远程 URL、Cookie、密码或验证码。
- 本机来源校验、同源请求校验、动作请求头，阻止跨站启动连接窗口。
- 登录页面、人工验证、未识别、窗口异常、历史状态保留分别显示。
- 通过官方域名、非登录页面路径、可见后台导航与抖音号核对账号；不根据文件或 Cookie 存在判断登录成功。
- 进程级浏览器目录锁与重复打开保护；控制命令限定检查/关闭。
- API 返回白名单状态，不返回 Cookie、令牌、原始异常或整页内容。
- 登录目录 `storage/platform_accounts/` 不进入默认备份/交付包。
- 只在连接窗口打开且页面可见时轮询状态；不刷新整页。

- 持久发布任务绑定账号、当前图文版本、图片 SHA256 和文案。演示内容禁止上传；准备、上传和正式提交为独立步骤。
- 实际编辑页填写与回读，核对 20 字标题、1000 字正文和图片数量；标注「内容由AI生成」。
- 明确人工确认后才执行提交。点击前再次核对账号、审核批准与稿件；崩溃或结果未知只回查，不自动重发。
- 精确标题与真实平台作品编号匹配后才登记。点击时间不伪造为平台发布时间。
- 从单作品区域解析可见播放、点赞、评论、收藏、分享指标；实际零与缺失不同。指标进入既有导入与复盘链路，当前不自动读取评论正文。
- 连接窗口打开时执行到期回访；关闭后常驻 Worker 可用同一登录配置启动只读回访。只读任务不能上传或发布；有未完成编辑稿时不启动后台配置。回访使用单独页面以保留编辑稿。
- 长任务期间持续连接心跳；停止项目前正常关闭连接，避免强制退出丢失登录状态。需要重新登录时停止后台重试并提示。
