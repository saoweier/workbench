## 完成判断

实际操作检查与阅读确认分开。学习步骤显示「我了解了」，不代表保存配置、制作或发布已经完成。

- 读取文字模型启用状态，不调用模型。
- 草稿实际进入下一创作步骤，才视为完成选题或样式。
- 提交任务与完成图片分别检查；失败或资料不足会显示原因。
- 只读取当前内容的活动版本，旧版本批准不能满足当前版本的批准步骤。
- 真实作品登记必须属于当前内容；演示、已撤回或其他作品不满足条件。
- 回访要求选择当前内容的真实作品，并存在指标快照；只有发布登记不算已有回访。
- 读取失败如实提示，可跳过或稍后继续。

教程自身不创建制作任务、发模型请求、修改 Skill、批准、发布或写入数据。目标页的固定模板预览与视频分镜计算仍按原页面行为运行，不产生模型调用。

内容规划的数量规则也在 Skill中维护：进入「技能管理与内容诊断 → 内容规划」，编辑「每页规划要点上限」「规划总页数上限」。当前默认不限，可以填正整数。明确指定的页数优先；新任务采用新规则，旧任务保留冻结版本。见 [C035报错与规则迁移](C035-规划规则与调研缺口-20261006.md)。
