# 动态讲解编辑台

## 怎么使用

1. 在顶部选择一份已完成的图文。页面直接给出章节、逐句讲稿和分镜，不必滚过所有讲稿才能看到设置。
2. 点击左侧章节切换内容。在右侧修改这一章的讲稿，系统自动按句编排。点击任意一句，查看中间的画面；点击“播放分镜”连续预览。此预览没有配音，也不调用模型。
3. 选择知识讲解、流程演示或对比分析。需要时为当前句子更换效果，或添加自己的 PNG、JPEG、WebP 图片。点“恢复原素材”可清除该句图片。
4. 选声音和语速，必要时展开讲解员设置更换角色。在线配音先确认发送讲稿，再点击固定在底部的“生成讲解视频”。完成后可播放、下载 MP4、配音、字幕与分镜计划。

“先看动态样片”提供约 92 秒、24 个分镜的实例，复用已有讲稿和配音；播放不调用语音服务。

## 内嵌视频导演 skill

[video-director 总纲](../backend/app/skills/video-director/SKILL.md) 定义按句编排、语义素材、图表来源、角色和字幕边界，以及预览与配音确认行为。

[三个预设](../backend/app/skills/video-director/presets.json) 是程序实际加载的规则。知识讲解侧重图片与关键词；流程演示侧重推进与清单；对比分析侧重并列与差异。用户逐句指定的效果和素材优先于预设。任务会保存具体规则版本，导出的分镜计划记录每句、来源图片、效果、素材及时间。

已有原图与本机语义插画组成基础素材：资料、编辑、审核、时间、页面、数据和观点。支持图片推近、关键词强调、流程推进、左右对比、逐项勾选、数据图表、素材切换与素材滚动。数值图表只使用原文提供的同单位数值，不编造指标。

## 当前边界

- 镜头与字幕按实际每页配音时长和句长分配，属于估算，不是逐字精确对齐。
- 图片角色轻微浮动；没有自动口型。上传的句子素材目前支持静态图片。
- 预览使用浏览器绘制，MP4 使用同一分镜计划的本机渲染。预览时长是估计，最终时长取决于配音。
- 原版逐页图文仍可选择，旧视频不被改写。

## 验证

`motion_studio` 隔离测试验证句子完整性、导演预设、图表数据来源、素材快照和实际 24 fps MP4；`studio_updates` 覆盖章节导航、逐句效果、素材替换、动态预览、生成与下载以及窄屏布局。测试不调用用户的在线配音服务。
