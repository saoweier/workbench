# 现有模板海报改造与维护

## 使用入口

创作室的“选择样式”直接展示实际海报示例，可放大查看。现有五套模板的标识保留，外观与写作规则同时升级：

| 模板 | 用途与视觉 |
| --- | --- |
| 手绘知识海报 | 奶油纸、绿色手写字、便签、铅笔分隔与主题小插画 |
| 杂志编辑海报 | 红黑衬线大字、不对称分栏、开放文章布局、杂志刊头与细线 |
| 深色科技图解 | 深色工程网格、薄荷色线路、方形模块、轨道与节点图案 |
| 活力拼贴海报 | 明黄画布、错落剪纸、胶带、印章、彩色贴纸与粗体标题 |
| 清晰数据图表 | 蓝白档案、明确列头、分类栏、规整线条与对照结构 |

五套风格由独立的布局结构生成，保留现有五个模板标识。视觉风格与内容形态独立：所有风格都能用于讲解、对比、流程、分类或排行，不再因选风格而改题型。普通讲解不增加排行序号；明确TOP10仍保留十个名次。

模板页默认“同题对照”：用完全相同的四个AI概念展示五种风格。也可切换“代表样例”查看讲解、两种做法对照、四步流程、演示榜单和十五项分类速查。示例没有编造真实热度或安装量。

“自动匹配”是选样式的入口，不是第六套模板。

## Skill与配套模板

打开 <http://127.0.0.1:8000/views/TemplateLibrary.html>。也可从创作室或流程技能页面进入“样式与模板 Skill”。

1. 左侧选现有模板。
2. 写作Skill决定写哪些信息、怎么组织、哪些内容必须保留。
3. 配套外观可改布局风格、底色、正文色、重点色、信息区底色、标题与正文字号、间距、圆角、标题字体及图案丰富度。各布局保留自身的分栏与线框规则。
4. “预览固定示例”只检查排版，不购买模型调用；示例内容不代表真实榜单。
5. “保存规则与模板”同时保存两部分；新任务使用新版本，已有作品和正在进行的任务保留开始时的版本。
6. 复制可创建自己的样式；历史版本可载入编辑器，再保存才生效。下载包含SKILL.md与template.json。

模板规则不会改变人工批准、发布、预算与账号权限。颜色、字号等设置受类型与可读性检查约束；不能在模板里执行代码。

内置包位于 `backend/app/skills/templates/<模板标识>/`。页面保存的工作区版本保存在事件记录中，优先于内置默认值；两部分以同一个指纹冻结进创作简报、技能快照与图片版本。新外观可复用现有渲染引擎；新增排版结构需要扩展本地引擎。
